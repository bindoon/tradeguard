# 可插拔组合回测

状态：done（2026-11-03，功能与页面草图经用户确认后完成实现与验收）

## 行为与边界

在现有 Python 服务内实现可插拔信号、组合/自定义交易策略、多股票共享资金的日线事件回放，以及本机控制台实验创建、策略启停与最终报告。股票池、市场、币种、来源、复权、日期、费用和执行假设均显式保存。参考 `../simnow/joinquant` 的上下文、组合选股和调仓流程，但重新实现时间/数据边界与 Decimal 账本，不复制凭据或简化撮合。

先支持已有日线数据；分钟/tick 接口应明确拒绝，不能合成缺失数据。分钟和盘口执行是后续扩展，不隐式采集全市场。当前证券主数据不能重建历史股票池；首版固定股票池研究必须在报告披露幸存者偏差、交易日覆盖与公司行为限制。

页面基线：用户确认的 `backtest-wireframe.png`（当前聊天视觉附件）。沿用浅色导航，实验列表、新建实验、策略管理、净值/基准与回撤、成交/订单/持仓/输入明细；空、加载、失败、数据不足状态均可见。

## 数据与运行

- 复用 `job_run/run_event`：实验配置、代码版本、输入清单、进度和小型结果摘要。
- 新增 `strategy_plugin_state`：安装代码与可变启停分离，状态只影响新任务。
- 新增 `backtest_artifact`：一个实验对应多份不可变行情切片与报告；与真实账户隔离，Alembic 管理结构。
- 插件来自内置类与已安装 Python entry points；HTTP 不接收或执行源代码。每个实验使用独立实例。
- 启动前冻结完整输入。离线回放只读取已冻结输入；重放校验代码与输入版本。
- 收盘决策最早次日开盘尝试成交。先卖后买、现金不为负、订单状态可追溯；无行情不可成交。日线止盈止损按收盘触发后次日执行，不伪造盘中路径。
- 前/后复权只作为显式的复权价格研究模型；原始价模型不含公司行为时明确披露，不宣称完整实际回报。

## 验收依据（先于实现）

1. 新增已安装插件无需修改核心；可启停；禁用后新实验拒绝，旧报告仍可读取/重放。
2. 扫描和回测对同一时点调用相同信号判断，均线的“两天前金叉”与依赖策略不退化为另一套入口。
3. 多股票共用资金：手续费、滑点、手数和现金约束被执行；顺序确定；账本现金+持仓=权益。
4. 当天收盘信号不能当天开盘成交；未来行情和其他市场/来源/复权数据不改变历史信号。
5. 缺行情、预热不足、缺基准保持缺口/未知；停牌、无效价格与成交限制有订单原因；不靠联网补假数据。
6. 行情修订、策略启停后，已保存报告保持不变；相同冻结输入和代码的重放结果一致。
7. CLI 输出单一 JSON；API 与 CLI 复用服务；HTTP 遵守本机写入边界。
8. 页面可创建多股票实验、管理策略、显示进度/失败，并展示已保存指标、净值、回撤、订单/成交、持仓、配置和限制；跨市场/来源结果隔离。
9. MySQL 迁移与集成测试、资金/时间边界测试、前端构建与页面关键流程验证通过；不修改现有测试断言掩盖失败。

## 顺序

插件与契约 → 冻结输入/迁移 → 组合策略/执行/报告 → CLI/API → 页面 → 数据库集成与浏览器验收 → 更新 README 和架构。
