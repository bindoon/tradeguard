## 目标与基线

用户批准工作台草图，并明确优先级：个人股票研究与买卖决策辅助，其次是他人本地部署，最后是独立远程公共展示与项目引流。已确认草图位于本次聊天附件 `tradeguard-workspace-wireframe.svg`。结构为侧边导航、市场/来源栏、全局搜索与股票标签、工作台、自选、提醒、个股图表及真实持仓。以当前 TradeGuard 为代码基线；OpenStock 855ca6af33ae0b86f8835ecda6c31707f4ec3891 只提供交互思路，不复制其代码。

## 意图与边界

- 首页从产品说明改为真实扫描、候选、同源变化、行业、自选及持仓复核工作台。
- 自选记录市场、证券、来源、复权、加入原因与关联批次；不代表持仓。
- 搜索读本地证券和覆盖状态；标签持有自己的市场、来源和日期。图表偏好只保存在浏览器。
- 价格提醒使用 Decimal 和显式来源/复权/交易日；新信号、过期快照提醒可去重、已读。缓存评估不声称实时监控，不写券商订单。
- 个人决策：复用显式版本纪律规则的买入/加仓检查；持仓结合已记录计划与同源收盘价提供止盈/止损复核。未知证据保持未知。没有实盘下单。
- CLI 与 HTTP 适配相同 Python 服务。MySQL/Alembic 新增自选、提醒条件、提醒记录；不连接或升级只读导入源。
- 公共站是独立静态包，正向白名单构造公开扫描/行情字段；不序列化账户、订单、自选、纪律、研究正文、内部错误、连接配置。
- 后续远程部署目标为 stock.zhiyu.hk；用户明确先满足本地需求，本轮仅提供可运行预览/部署包，不替换线上站点。源码公开前仍需解决 provenance 所列来源权利与许可证，不擅自修改仓库可见性。
