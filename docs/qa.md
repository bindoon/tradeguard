# 首版验收目标

验收依据在实现前记录，后续测试验证这些可观察行为。

- PostgreSQL 从空库迁移后可运行 CLI；升级后的模型无未生成变更。
- 相同来源、证券、复权和日期的行情重复导入不增加重复记录；非法 OHLC 不写入。
- 指定日期扫描不使用未来行情；缺当天行情/历史不足明确列出，重复扫描保留独立批次。
- 同一账户的完整快照原子提交；导入无效快照不改变当前底牌；同 ID 不同内容拒绝覆盖。
- 纪律检查缺规则、持仓、止损或汇率不能通过；按交易后敞口和最大损失判断；计划止损不冒充券商确认。
- 报告保留来源、观测期、披露时间；所有一期功能通过 CLI 直连数据库完成。
- 旧 MySQL 只读迁移、分批提交；恢复游标与目标行情原子提交，默认 daily 不联网刷新。
