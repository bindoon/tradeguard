## ⛔ 准入门槛（没达标之前，本手册默认锁定）

> **写在最前面，因为这是对我最重要的一条。**
>
> 价值投资是所有流派里**最容易给我的坏习惯（死扛亏损、下跌补仓）提供"知识分子借口"**的一个。"越跌越买""别人恐惧我贪婪"这套话，能让我把每一次接飞刀都包装成"我在做价值投资"。我的阿里从 300 拿到 72 才割，就是把死扛伪装成长期持有的活教材。

真正的价值投资"越跌越买"成立，必须**同时**具备下面三项能力。**有任何一项做不到，就不许用本手册，回去用激进/趋势手册那套"机器替我卖"的护栏练纪律：**

- [ ] **① 会做基本面估值**：能独立算出一家公司的内在价值区间，而不是看价格/消息/感觉。
- [ ] **② 对标的有破产级笃定**：理解它的商业模式和资产负债表，确信它不会倒。
- [ ] **③ 铁一般的情绪纪律**：能做到一只票跌 50% 还不动摇、不恐慌割肉、不因难受而乱补。（⚠️ 阿里 300→72 那次就是栽在这条：没借钱、逻辑也没变，纯粹看着账户一天天跌、煎熬到受不了而割在底部——这是反向赌徒信号，见通用手册 4.1b。门槛③不只防"乱补"，也防"恐慌割"。）

> **自检**：上面三条，我现在能诚实打勾的有几条？不足三条 → 关闭本手册。

<a name="第一章"></a>
## 第一章：核心原则

价值投资和趋势交易最根本的区别，在于**对"价格下跌"的解读**：

| | 趋势/激进手册 | 价值投资手册 |
|---|---|---|
| 价格下跌意味着 | 趋势走坏 → 止损离场 | 可能更便宜了 → （逻辑不变则）加仓机会 |
| 卖出依据 | 价格（移动止损） | 价值（高估了 or 逻辑证伪） |
| 止损方式 | 价格止损（移动/固定） | **逻辑止损，不用价格止损** |
| 持仓时间 | 数周~数月 | 以年计 |
| 盯盘 | 趋势仓每周看 | 几乎不看价格，看公司基本面 |

核心信条：
- **价格是你付出的，价值是你得到的。** 只在价格明显低于内在价值（有安全边际）时买。
- **市场短期是投票机，长期是称重机。** 短期波动不构成卖出理由。
- **不懂不做。** 只在能力圈内出手。

<a name="第二章"></a>
## 第二章：能力圈与买入标准

买入前必须能用人话回答（写下来，写不出就不买）：

- [ ] **这家公司靠什么赚钱？** 商业模式我能一句话说清。
- [ ] **它的护城河是什么？** 为什么竞争对手抢不走？
- [ ] **它会不会倒？** 资产负债表健康吗？现金流如何？
- [ ] **它大概值多少钱？** 我估算的内在价值区间是多少？依据是什么？
- [ ] **现在价格相对内在价值，有多少安全边际？** （建议至少打 7 折以下再买）
- [ ] **什么情况会证明我看错了？** （这就是后面的逻辑止损条件）

> 任何一条答不上来 → 这不在我的能力圈，不买。这不是趋势手册里"看好就上"，价值投资买的是**你算得清的便宜**。

<a name="第三章"></a>
## 第三章：仓位结构——核心仓 + 子弹仓

> 价值投资里也有"机动"，但它不是短线投机仓，而是**子弹仓/现金储备**——用来在更便宜时加仓、或抄底新的低估标的。**它按估值动用，绝不做短线波段。**

| 仓位 | 作用 | 动用依据 |
|---|---|---|
| **核心仓** | 已建仓的低估好公司，长期持有 | 估值/逻辑 |
| **子弹仓（现金储备）** | 留着的现金，等市场报出更便宜的价 | **只因估值，不因价格反弹的兴奋** |

规则：
- 单一标的不超过核心账户 25%~30%（通用手册红线），所以**建仓天然分批**，留出子弹仓空间。
- 子弹仓是现金，不是"随时想交易的痒"。它可以长期趴着不动，等机会。
- **绝不为了"做点什么"而动用子弹仓。** 没有符合标准的便宜货，就一直持有现金。

> ⚠️ **物理隔离提醒**：短线投机的机动仓只存在于激进手册/机动账户。这里的子弹仓是价值账户里的现金，两者规则不同、不互通。别把价值子弹仓拿去做短线，也别把短线机动仓说成"价值补仓"。

<a name="第四章"></a>
## 第四章：子弹仓与补仓纪律（补仓 vs 死扛）

> **这一章是本手册的生死线。** 价值投资的"越跌越买"和我过去爆仓的"下跌加仓"，**动作一模一样，区别只在于有没有真做基本面**。所以补仓前必须过下面这道闸。

### 4.1 允许补仓的唯一情形

价格更低了，**且同时满足**：

- [ ] 我**重新做了一遍基本面**（不是看价格，是看公司有没有变）
- [ ] 下跌是**市场情绪/系统性原因**，不是公司基本面恶化
- [ ] 我能写下一句话：**"为什么更便宜了，但我的买入逻辑依然成立。"**
- [ ] 补仓后单一标的**仍不超过** 25%~30% 上限
- [ ] 我的内在价值估算**没有因为新信息而下调**

全部打勾 → 可以补。任何一条不满足 → **不许补，这就是死扛**。

### 4.2 「补仓 vs 死扛」检查清单（每次想补仓前，逐条问）

| 问题 | 价值补仓（可补） | 死扛接飞刀（禁止） |
|---|---|---|
| 我为什么想补？ | 因为它更便宜了，价值还在 | 因为我难受/想摊低成本/想快点回本 |
| 我重新做基本面了吗？ | 做了，逻辑没变 | 没有，只是看着价格跌 |
| 公司基本面变了吗？ | 没变 | 变差了 / 我不知道 |
| 我在用什么钱补？ | 预留的子弹仓现金 | 借的钱/挪用别处/加杠杆 |
| 补了会超上限吗？ | 不会 | 会，或者已经满仓还想补 |
| 我心里在想什么？ | 平静，按计划 | "搏一搏""一把捞回来" |

> **只要右栏命中任何一条，立刻停手**——这不是价值投资，是第八章（通用手册）说的赌徒信号，该清仓休息两周。

### 4.3 补仓的硬上限

- 单一标的补到上限（25%~30%）就**绝对停止**，不管多便宜。
- 补仓必须用**子弹仓现金**，绝不借钱、绝不加杠杆、绝不挪用别的仓位。
- 基本面**恶化**导致的下跌：不补，反而要走逻辑止损（第五章）。

<a name="第五章"></a>
## 第五章：卖出——逻辑止损与估值卖出

> 价值投资**不用价格止损**。一只低估好公司跌 20% 不是卖出信号。卖出只有三个理由：

### 5.1 卖出的三个理由

1. **估值卖出（涨上去了）**：价格涨到明显高于内在价值（高估），安全边际消失甚至变成"安全负债"。
2. **逻辑止损（看错了）**：买入逻辑被证伪——护城河被破坏、商业模式崩塌、财务造假、行业被颠覆。**问自己"如果今天才认识这家公司，以现在的基本面我还会买吗？"不会 → 卖。**
3. **机会成本**：出现一个安全边际明显更大的标的，且现金/子弹仓不够，可换仓。

### 5.2 不构成卖出理由的（重点，治我手痒）

- ❌ 价格跌了（逻辑没变就不卖，甚至该看子弹仓补仓条件）
- ❌ 价格涨了一点点就想落袋（没到高估别卖，让价值兑现）
- ❌ 别人都在卖 / 消息面恐慌（不听消息，凭自己估值判断）
- ❌ 拿得难受 / 想换个刺激的（这是赌徒信号，不是卖出理由）

> 价值投资里"会卖"= 卖在高估，而不是卖在手痒或恐慌。

<a name="第六章"></a>
## 第六章：持仓管理与复盘

价值投资**看公司，不看价格**。检查频率以基本面节奏为准：

**季度检查（跟财报走，不需要天天看价格）：**
- [ ] 这个季度公司基本面有没有变化？护城河还在吗？
- [ ] 我当初的买入逻辑还成立吗？
- [ ] 内在价值估算需要更新吗？（上调/下调）
- [ ] 当前价格相对内在价值，是低估、合理、还是高估？
- [ ] 子弹仓有没有可以出手的机会？

**每年一次深度复盘：**
- 用通用手册的复盘模板，但把"做对/做错"聚焦在**估值判断**和**纪律执行**上，而不是价格涨跌。

> 沿用我自己的好规矩：**周日安心遛娃练功。** 价值投资本就不需要盯盘，这一点对我反而是优势——少看价格，少手痒。

## 附录：价值投资常见错误（对我的高危区）

**错误1：把死扛伪装成长期持有** —— 逻辑已坏还不卖，安慰自己"价值投资要拿得住"。纠正：逻辑止损照走，拿得住的前提是逻辑还在（阿里 300→72 的教训）。

**错误2：把接飞刀伪装成价值补仓** —— 没做基本面，只因为难受/想摊成本就补。纠正：过 4.2 检查清单，右栏命中就停手。

**错误3：用价格止损做价值投资** —— 跌 20% 就割，结果割在最便宜的地方。纠正：价值投资不用价格止损，用逻辑止损。

**错误4：能力圈外出手** —— 算不出内在价值也买，本质是赌。纠正：算不清就不买，这只是看起来像价值投资。

**错误5：子弹仓拿去做短线** —— 闲不住，把价值账户的现金拿去玩波段。纠正：子弹仓只按估值动用，想做短线去激进账户。

**错误6：卖太早** —— 涨一点就落袋，没让价值充分兑现。纠正：没到高估不卖。

## A 股适配（价值打法）

> 完整的市场差异见通用手册附录D。价值投资在 A 股**更难**，准入门槛要卡得更死：

- **政策市权重极高**：A 股估值受政策、流动性、监管影响巨大，纯基本面常常"短期失灵"。买入逻辑里**必须把政策/行业监管风险算进去**。
- **低估长期不修复**：A 股优质公司可能多年低估不涨，需要比美股**更强的耐心和更明确的逻辑止损条件**——别把"它就是不涨"误当成"被低估的机会"。
- **退市风险上升**：注册制后退市增多，"壳价值"消退。**以前"死扛等借壳重组"的幻想现在更危险**，逻辑止损（基本面证伪）要执行得更果断。
- **子弹仓补仓**：A 股急涨急跌、情绪极端，子弹仓补仓更要严守 4.2 清单，别被"跌得多了"的情绪诱导（A 股跌停连环更吓人）。
- **能力门槛**：上面这些意味着——**没达到通用手册的价值准入三门槛，在 A 股更不该用价值打法**，先用激进手册的护栏。
