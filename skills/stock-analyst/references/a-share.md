# A股版分析手册

> 做 A股 分析时读这份。套用 SKILL.md 的四层评分卡，本文件提供 A股 专属的：宏观/资金面取数、数据源、雷区清单、行业搜索模板、估值锚。
> 把搜索词里的 `[YEAR]` 换成当前年份、`[MONTH]` 换成当前月份。

---

## 一、A股的特殊性（取数前先记住）

- **政策市**：政策催化的权重远高于美股。发改委/工信部/政府工作报告/产业规划是宏观层的第一信源。
- **资金面按口径追踪**：龙虎榜、ETF 份额、公募持仓等可作证据；供应商“主力净流入”是算法估算。北向数据先核对最新披露制度，不假设旧接口仍提供当前日频净买入。
- **交易制度**：T+1、涨跌停（±10%/±20% 科创创业、±5% ST）。这些影响的是**进场/止损执行**（属 trading-discipline），分析阶段了解即可。
- 估值以**相对估值 + 政策溢价**为主，PE/PB 历史分位是主锚。

## 二、模式一：行业趋势扫描（搜索策略）

按顺序执行，共 4-6 次搜索。

```
搜索1 政策层（A股最关键）
  "[YEAR] 国家战略 重点扶持 产业政策 A股"
  "发改委 工信部 最新政策 [YEAR][MONTH]"
  "政府工作报告 重点方向 [YEAR]" / "十四五/十五五 产业规划 落地进度"
  目标：找出当前政策催化最强的方向

搜索2 资金层
  "A股 行业资金流向 主力净流入 [本周/本月]"
  "site:hkex.com.hk 北向 披露 调整"（先确认当期可得字段与频率）
  "公募基金 重仓行业 [YEAR] 季报"
  目标：区分实际披露的申赎/持仓、滞后快照和供应商估算，不能用持仓市值涨幅代替净买入

搜索3 市场层
  "A股 板块涨幅排行 [YEAR][MONTH]"
  "机构调研 热门行业 最新"
  目标：判断市场情绪和资金共识

搜索4 产业景气
  针对搜索1的热点行业，搜其景气指数 / 行业增速 / 价格趋势
  目标：确认基本面是否支撑，而非纯主题炒作
```

> 板块轮动判断专项：
> ```
> "[板块A] 转 [板块B] 资金轮动 [YEAR][MONTH]"
> "[行业] ETF 官方 份额 申赎"（净流量与资产价格变化分开）
> "[行业]ETF 份额 增减 [YEAR][MONTH]" / "机构 龙虎榜 [行业] [YEAR][MONTH]"
> ```

## 三、模式二：个股深度分析（搜索策略）

共 6-8 次搜索。

```
搜索1 基本信息：  "[股票名称] 股票 所属行业 市值 主营业务" → 定位产业链位置
搜索2 宏观层：    "[所属行业] 行业趋势 市场规模 政策 [YEAR]" → 赛道是否上升期
搜索3 竞争层：    "[公司名称] 市场份额 竞争对手 核心竞争力" + "[行业] 龙头 市占率"
搜索4 产业链层：  "[行业] 产业链 上下游 利润分布" + "[公司名称] 议价能力 毛利率" → 是否三高环节
搜索5 财务层（先跑 longbridge，再 web_search 补充）：
  longbridge quote 600519.SH          # 6位代码 + .SH/.SZ
  longbridge financial-statement SYMBOL --kind ALL
  longbridge financial-report SYMBOL --latest
  longbridge valuation-rank SYMBOL
  longbridge analyst-estimates SYMBOL
  关键财务直接核对：巨潮/交易所公司定期报告、业绩预告和IR原文；摘要网站仅作发现线索
搜索6 雷区检测：  见下方第四节
```

## 四、A股雷区清单（个股必查）

```
"[公司名称] 大股东减持 [YEAR]"          → 减持
"[公司名称] 股权质押 比例"               → 高质押（>50% 警惕爆仓）
"[公司名称] 商誉 减值 风险"              → 商誉地雷
"[公司名称] 应收账款 现金流"             → 收入质量（赚的是利润还是白条）
"[公司名称] 监管函 问询函 处罚 [YEAR]"   → 监管风险
"[公司名称] ST 退市 风险 财务造假"       → 退市新规红线
```

命中任意一条都要在【雷区检测】里点名，严重的（造假/退市风险/质押爆仓）直接压低评级到"回避"。

## 五、数据源（A股）

> **取数原则**：长桥便捷取行情/结构化摘要；关键定量判断直接读一手披露，无需等长桥失败。来源入口与方法见 [一手数据来源与溯源](data-sources.md)。

### 便捷采集：longbridge CLI

Symbol 格式：上海 `600519.SH`、深圳 `000568.SZ`。完整命令见 `longbridge` skill；常用映射：

```bash
longbridge quote SYMBOL
longbridge kline history SYMBOL --start YYYY-MM-DD --end YYYY-MM-DD --period day
longbridge financial-statement SYMBOL --kind ALL
longbridge financial-report SYMBOL --latest
longbridge valuation-rank SYMBOL              # PE/PB/PS 行业分位
longbridge analyst-estimates SYMBOL
longbridge news SYMBOL
longbridge filing SYMBOL                      # 公告/监管披露
```

> 缓存建议：财务数据 TTL 24h（T+1），报价 TTL 短（分钟级）。

### 原始证据：官方披露与统计网页

直接查巨潮/交易所报告、统计局、人民银行、海关、工信部和能源局等原始表格、公告与方法说明。保存具体链接、数据期、披露日与单位；东方财富/雪球摘要用于发现线索。缺历史序列就注明无法算分位，不把当前估值当历史分位。

### 兜底：AKShare（长桥缺项时）

`pip install akshare`。以下维度 longbridge 较弱或缺失时再用，**不要作为默认取数方式**：

| 接口 | 用途（longbridge 缺项） |
|---|---|
| `stock_individual_fund_flow(stock)` | 供应商算法估算的个股资金流，非机构账户净买入 |
| `stock_sector_fund_flow_rank(symbol)` | 行业资金流估算排行，核对分类方法 |
| `stock_hsgt_north_acc_flow_in_em(symbol)` | 历史北向数据线索；先确认最新日期与披露变化，不承诺当前日频 |
| `stock_board_industry_summary_em()` | 申万行业汇总 |
| `stock_hold_control_em(symbol)` | 大股东持股/质押（雷区） |
| `stock_notice_report(symbol)` | 公司公告/监管函（雷区） |
| `stock_a_pe(symbol)` | PE 历史 → 算当前分位 |
| `stock_financial_abstract_ths(symbol)` | 财务摘要（长桥三表不够时） |

### 兜底：Tushare Pro（积分制）

已有授权且需要补充时，检查当前官方文档和权限。[`pro.top_inst()`](https://tushare.pro/document/2?doc_id=107) 是龙虎榜机构席位交易明细，不是机构完整持仓；[`pro.hsgt_top10()`](https://tushare.pro/document/2?doc_id=48) 是特定范围交易明细，不能当全市场北向持仓或净流入。接口能返回历史记录不代表当前口径仍连续。

## 六、A股相对估值锚

- **主锚**：PE / PB 的**历史分位**（近 5 年处于什么水位），比绝对值更有意义。
- **政策溢价**：政策强催化的方向，市场会给溢价，单看 PE 会显得"贵"，需结合预期增速（PEG）。
- **中特估/低估值国企**：看 PB + 股息率，重估逻辑而非成长逻辑。
- 横向对比：同行业龙头 vs 二线的估值差，判断是否有合理性。
