# 一手数据来源、溯源与持续取数

用于 stock-analyst 的题材探索、财务与资金证据核验，以及新闻/截图溯源。单纯询问来源时直接回答来源与获取方法，无需输出评级。

## 使用顺序

- 追踪新闻或图表：先用下方“溯源与题材研究”还原来源，再查对应的一手入口与指标口径。
- 探索行业或方向：先拆可验证的假设，再从公司披露、产业数据和资金统计中选择相关指标。
- 需要以后重复获取：使用末尾的来源卡，记录具体表名、查询条件、发布节奏与权限。

## 取数原则

- **采集工具与原始来源分开**：长桥 CLI/MCP 适合便捷获取行情、结构化财务和新闻；公司 IR、监管披露、交易所、政府统计、协会原始调查用于核验和建立长期指标。无需等长桥失败才查一手源。媒体、聚合 API、AKShare 等是发现或采集渠道，不自动成为原始发布者。
- 按指标选择来源，不按供应商品牌限制研究范围。供应商 skill 的单平台推荐限制不适用于本项目的一手来源研究；长桥命令仍按其 `--help` 和已授权能力使用。
- 当前数字、披露制度、权限和 API 能力在使用时查官方页面。目录是入口，不是已获取的数据；区分“入口已核实”“本次数据已取回”“仅找到媒体转述”。
- 证据优先级：原始表格/申报/报告及方法说明 → 发布方公开摘要 → 有明确引用的媒体 → 未核实转载。公司指引、协会样本调查与已实现事实分开。
- 原文链接放在具体判断旁。找不到原报告时保留“未核实”，不根据同源转载制造独立交叉验证。

## 溯源与题材研究

### 新闻、截图、报告溯源

提取机构、团队、作者、图题、篮子/序列代码、单位、时间区间和脚注；用英文原词、精确图题、代码及官方域名检索。年份不明时先核实，不从截图月份猜年份。

还原“原始观测 → 汇总方法 → 报告 → 媒体转述”的链条。读轴标签、分母和脚注，区分累计交易流量、持仓、收益和模型估算。图像读数标为近似提取，不能冒充原始序列。

### 题材、行业、方向探索

先把题材拆为可证伪的问题，例如“AI 资本开支是否转成供应商收入”，再选少量有解释力的指标：

`假设 → 需求/供给/价格/盈利/资金指标 → 发布者 → 实际获取 → 时间与口径对齐 → 支持/反证/缺口`

优先用下游需求或开支、上游出货或收入、盈利或库存形成证据链；资金与价格观察市场行为，不代替需求验证。没有限定市场时可先用全球产业数据探索，再按标的所在地补披露；只有缺失信息阻碍分析时才提问。

### 题材选源示例

- **AI/半导体**：云厂商 IR 的 CapEx/指引 → GPU、代工、设备商披露的收入、订单、毛利 → MOPS 月营收、SIA/WSTS 周期数据 → 用电/建设统计。各层有各自滞后，广义 CapEx 不全是 AI，避免把产业链同一笔收入重复相加。
- **电力/储能/新能源**：能源局/EIA 装机与用电、招标或公司订单原文 → 出货、价格、库存、回款；项目规划容量与已并网容量分开。
- **消费/出口**：统计局/Census 消费、海关商品量价 → 企业销量、同店增长、毛利；名义销售额增长不必然是销量增长。
- **医药**：试验登记及结果、FDA 文件 → 公司授权协议与收入；区分里程碑总额上限、已到账金额和销售分成。

新题材沿用相同方法寻找对应主管部门、交易所、协会原始调查与公司披露。目录没有的来源可以补入，但需保留官方说明链接及核验状态，不猜测数据接口。

## 指标口径与持续取数

### 容易产生错误结论的替换

| 看到的指标 | 不应直接推出 | 需要补的定义或证据 |
|---|---|---|
| 某 Prime Book 卖出 | 全球全部对冲基金卖出 | 账户样本、覆盖资产、汇总方式、是否包含衍生品 |
| 从期初累计净流量回零 | 所有仓位清仓 | 期初存量、流量分母、估值和成分调整；流量不是持仓 |
| 13F 季度市值下降 | 最近几天减仓 | 两期股数、价格、拆股、申报修订与证券覆盖；13F 无法观察每日路径 |
| FINRA 每日卖空成交高 | 空头余额增加或方向看空 | 未平仓空头、平仓、交易场所覆盖；当天卖空可能当天平仓 |
| ETF AUM 增加 | 同额资金流入 | 份额变化、净值和发行人申赎数据。估算可用份额差×适当净值，但注明时点、拆分与汇率影响 |
| 期货杠杆资金净多下降 | AI 现货股票遭同额抛售 | 合约、交易者分类、期权折算及现金市场证据 |
| 网站“主力净流入” | 某类机构账户真实净买入 | 大单划分/主动买卖算法；这是供应商估算，与交易所投资者分类统计不同 |
| 北向历史接口仍能调用 | 当前仍有同口径日频净买入 | 最新披露规则、最新真实交易日、是否停更/历史/估算；成交总额、额度余额不替代净买入 |
| 两家媒体引用同一报告 | 两个独立来源确认 | 回溯到原始观测，按源头去重 |
| 全产业销售或资本开支增长 | 某题材需求同比同幅增长 | 产品分部、量价拆解、建设与确认收入的时滞、非题材业务占比 |

### 财务与历史比较

- 明确单位、币种、财年/自然年、单季/累计/TTM、GAAP/non-GAAP、季调、样本与合并范围。XBRL 同一标签可能有多个期间或修订值，保留 accession、form、filed、start/end，不按标签名直接拼表。
- 从累计报表差分得到单季时，核对期间与可比性。现金流、存量资产负债和增长率不可混用；公司自定义 FCF、ARR、订单口径需读定义。
- “历史第几大”“-2.1个标准差”等说法需有样本起止、频率、均值/标准差方法和样本量。缺原序列只归因为报告说法，不声称独立复算。
- 变化金额对齐价格与汇率日期；回测按当时已公开的数据构建，不能用后来修订财报或季度末日期冒充可得日期。
- 同一主题篮子确认成分和调整历史。无法取得 `GSXGGLAI` 等专有篮子定义时，自建篮子必须另命名，不能称为高盛原序列。

### 获取与复用

1. 优先官方导出/批量文件/有文档的 API；其次原始网页、PDF/电话会。长桥与其他聚合渠道便捷取数时仍留上游出处。PDF/图片需要提取时使用相应技能；引用数字核对原页。
2. SEC 请求按[官方获取说明](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)设置可识别 User-Agent、遵守当前访问限制；其他站点依官方文档处理注册、配额和许可。不猜测公共 API、不绕过权限。密钥通过环境或已有授权工具读取。
3. 选一个具体指标做小样取回，检查最新日期、缺失值、修订和导出格式。只有入口可访问而未取到数据时，状态保持“入口已核实”。
4. 记录查询条件、表名/序列 ID、URL、获取时间（含时区）、原始文件与转换公式。零值与缺失值分开；采集失败不能变成“没有交易”。
5. 更新节奏跟发布节奏走：季报在披露后更新，月报跟月度日历，周报跟实际发布日；每日轮询不能把季度快照变成实时仓位。修订数据保留版本，不静默覆盖已引用值。
6. 无权限时交付官方公开摘要、申请入口和方法不同的代理指标，明确缺口；不假设用户愿意订阅、注册或部署抓取服务。

## 输出与复用模板

短答给直接来源、获取方式和关键边界即可。题材研究用下表整理实际证据，并说明事实、预期/估算、推断和反证条件：

| 验证环节/指标 | 原始发布者及具体链接 | 数据期/披露日 | 获取方式/权限 | 更新频率/滞后 | 证据与局限 |
|---|---|---|---|---|---|
| 需求 | | | | | |
| 供给/价格 | | | | | |
| 收入/盈利 | | | | | |
| 资金/市场行为（相关时） | | | | | |

需要持续获取时，按指标保存来源卡。未知项写“待核实”，不补造接口、费用、历史覆盖或精确发布时间。

```yaml
indicator: 指标名、验证问题、表名/序列ID
source: 原始发布者、上游观测来源、原始披露/调查/摘要/转载/估算
links: 本次报告或表格的具体URL、官方目录或接口文档
verification: 数据已取回/原文已核实但无原序列/入口已核实/转载未核实/权限受限
timing: 观测期、披露时间、获取时间（含时区）、频率和滞后
scope_and_basis: 样本、资产/地域、分母、单位、币种及会计/季调口径
access: 免费/注册/付费/机构授权/待核实
retrieval: 网页操作路径/官方导出/有文档API/已验证CLI命令及查询参数
history: 历史覆盖、修订及方法变化
evidence: 原文页码/表名/脚注、实际留存文件及校验值（适用时）
transformation: 换算或估算公式；无则无
interpretation: 能支撑的判断、局限、替代指标及不等价之处
```
